# 龙虾日报 · 需求倒推器（需求层）

## 这个 skill 在干什么

龙虾日报流水线的第二层：**需求倒推**。它扫描最近的对话记录，回答一个问题——"用户最近关心什么？"

```text
对话记录（sessions JSONL）
  -> 清洗（过滤系统事件/URL噪音/重复）
  -> 提取需求信号（显式 + 隐式）
  -> 更新 data/user-profile.json（需求画像）
```

这是"**系统和用户越聊越懂用户**"的核心机制：画像持续更新，供评分层判断"什么内容与你相关"。

## 设计理念：显式 + 隐式双通道

| 类型 | 定义 | 提取方式 | 置信度 |
|---|---|---|---|
| **显式需求** | 用户直接说的（"我关心XX"、"帮我找XX"、"我想做XX"） | 规则匹配动词短语 | 0.8 |
| **隐式需求** | 用户反复问/讨论的高频主题 | 频次统计（≥2 次才收录） | 0.3-0.7（按频次） |

原则：**显式优先，隐式辅助**。显式是用户明确表达的，权重高；隐式是行为推断，必须标置信度，宁缺毋滥。

## 配置项

| 项目 | 默认值 | 说明 |
|---|---|---|
| 会话目录 | `~/.openclaw-lobster2/agents/main/sessions/` | OpenClaw 会话 JSONL 目录，可通过 `--sessions` 覆盖 |
| 扫描天数 | 1 天 | 昨天到现在的对话 |
| 画像路径 | `data/user-profile.json` | 输出画像，QMD 可索引 |
| 隐式最低频次 | 2 | 低于此频次的词不收录 |

## 执行步骤

### 1. 运行脚本

```bash
python3 scripts/extract_needs.py
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--days N` | 扫描最近 N 天（默认 1） |
| `--sessions PATH` | 指定会话目录（非 OpenClaw 用户可指向自己的对话文件） |
| `--profile PATH` | 指定画像输出路径 |
| `--min-implicit N` | 隐式需求最低频次（默认 2） |
| `--dry-run` | 只展示不写文件 |

### 2. 检查输出

脚本会打印：

```text
📝 读取 40 条用户消息（最近 1 天）
🔍 显式需求信号 Top 10: ...
🔍 隐式高频主题 Top 10: ...
🏆 当前 Top 5 需求: ...
```

### 3. 画像更新逻辑

`data/user-profile.json` 结构：

```json
{
  "version": 1,
  "updated_at": "2026-08-10T...",
  "needs": [
    {"keyword": "Codex 反代", "type": "explicit", "weight": 4.5,
     "confidence": 0.8, "first_seen": "...", "last_seen": "..."}
  ],
  "meta": {"scan_days": 1, "explicit_count": 12, "implicit_count": 8}
}
```

- **时间衰减**：已有需求每次扫描权重 × 0.7（旧需求逐渐让位给新需求）
- **权重上限 5**：防止单一需求无限膨胀
- **清理**：权重 < 0.3 的需求删除（画像不膨胀）
- **上限 50 条**：最多保留 50 条需求

## 与其他 skill 的协作

龙虾日报流水线（共 5 个 skill）：

```text
lobster-rss-collect      → 采集层（RSS/API → 候选 JSON）
lobster-needs-extract    ← 本 skill：需求层（对话 → 需求信号 → 画像）
lobster-score-filter     → 评分过滤（候选 × 画像 → Top 3-5）
lobster-distill          → 提炼（三级笔记 + 概念提取）
lobster-daily-orchestrate → 编排推送（串全流程 → 飞书云文档）
```

本 skill 可被单独复用（任何需要"从对话提取用户兴趣"的场景），不依赖其他 4 个。

## 关键守则

1. **只提取，不评分**：只更新画像，不决定推什么。
2. **显式优先**：用户明说的需求权重最高。
3. **隐式标置信度**：推断的需求必须标注 confidence，宁缺毋滥。
4. **清洗先行**：过滤系统事件、URL 列表、重复消息，噪音进画像就是污染。
5. **零第三方依赖**：只用 Python 标准库。
6. **可配置**：非 OpenClaw 用户通过 `--sessions` 指向自己的对话文件即可复用。
